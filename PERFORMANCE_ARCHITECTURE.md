# Arquitetura de Performance — v1.2.2

## Métricas principais

- P&L líquido;
- taxa de acerto;
- fator de lucro;
- drawdown máximo em USD e R;
- ganho médio;
- perda média;
- expectância monetária;
- R médio;
- custos totais;
- sequência máxima de ganhos;
- sequência máxima de perdas.

## Filtros

Journal e Performance podem recortar o histórico por:

- ativo;
- conta;
- período;
- tag;
- origem;
- status/resultado/sessão no Journal.

## Tags

Tags são metadados organizacionais definidos pelo usuário e servem para revisão e segmentação de performance. Elas não representam sinais ou previsões.

## Fonte de dados

Operações podem vir de:

- MT5 / Exness;
- registro manual;
- demonstração.

A fonte é preservada no Trade para permitir auditoria do histórico.
